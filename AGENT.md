# AGENT.md

**The agent guidance for this repository lives in [CLAUDE.md](CLAUDE.md). Read that file.**

This file exists because some tools look for `AGENT.md` and others look for `CLAUDE.md`. It is a
pointer, deliberately, rather than a copy: the two files were previously byte-identical 298-line
duplicates with nothing keeping them in sync, so every edit had to be made twice and any missed
edit left two documents disagreeing about the same rule.

Do not paste the guidance back into this file. Edit `CLAUDE.md`.
