WEB PROJECT

PoRedoImage.Web

  • Program.cs — composition root
  • 5 VSA feature slices (endpoints)
  • SSR + WASM components
  • Key Vault · Serilog · OTel · Auth · Radzen

CORE

Application + Domain

  • IImageAnalysisOrchestrator — single entry
  • Domain: Entities + 6 Interfaces
  • Infrastructure: 4 Services + 2 Repositories
  • Dependency inversion: Domain → Infra

SHARED

PoRedoImage.Shared

  • DTOs for all API contracts
  • ProcessingMode + UserImageKind enums
  • BulkGenerate + UserImage DTOs
  • Used by Web, App, Infra, Client
