System Flow

Full sequence diagram: Key Vault startup, authentication, image analysis (CV → OpenAI → Gemini), gallery save, and 10-slot parallel bulk generation.

sequenceDiagram
    autonumber
    actor User as 👤 User
    participant Blazor as "Blazor SSR\n(PoRedoImage.Web)"
    participant Auth as "Auth Middleware\n(Cookie / OIDC)"
    participant API as "Minimal API\n/api/*"
    participant Orch as "ImageAnalysisOrchestrator\n(Application Layer)"
    participant CV as "Azure Computer Vision"
    participant OpenAI as "Azure OpenAI\nGPT-4.1-nano"
    participant Gemini as "Google Gemini\ngemini-2.5-flash-image"
    participant Tables as "Azure Table Storage"
    participant KV as "Azure Key Vault"

    Note over Blazor,KV: Startup — Secrets loaded from Key Vault (30-min rotation)
    Blazor->>KV: AddAzureKeyVault (DefaultAzureCredential)
    KV-->>Blazor: ConnectionStrings · ApiKeys · ClientSecret

    Note over User,Auth: Authentication Flow
    User->>Blazor: GET /login
    Blazor-->>User: Login.razor rendered
    User->>Auth: GET /challenge-microsoft (Prod) or /dev-login (Dev)
    Auth->>Auth: Issue cookie ClaimsIdentity
    Auth-->>User: Redirect → / (Studio)

    Note over User,Tables: Image Analysis — Regeneration Mode
    User->>Blazor: Upload image (base64) + select mode
    Blazor->>API: POST /api/images/analyze {ImageData, Mode=ImageRegeneration}
    API->>API: Validate magic bytes (JPEG/PNG) + DescriptionLength
    API->>Orch: ProcessAsync(request)
    Orch->>CV: AnalyzeAsync(imageBytes)
    CV-->>Orch: tags[] + confidence + description
    Orch->>OpenAI: EnhanceDescriptionAsync(description, tags, length)
    OpenAI-->>Orch: enhancedDescription + tokens
    Orch->>Gemini: RegenerateImageAsync(imageBytes, enhancedDescription)
    Gemini-->>Orch: regeneratedImage bytes
    Orch-->>API: ImageAnalysisResponse {Description, RegeneratedImageData, Tags, Metrics}
    API-->>Blazor: 200 OK ImageAnalysisResponse
    Blazor-->>User: ImageRegenerationResultsPanel updated

    Note over User,Tables: Save Result to Gallery
    User->>Blazor: Click "Save to Gallery"
    Blazor->>API: POST /api/user-images/save-result {ImageData, Kind=Regeneration}
    API->>Tables: UpsertAsync(UserImage entity)
    Tables-->>API: 204 No Content
    API-->>Blazor: SaveImageResponse {Id, ImageUrl}
    Blazor-->>User: Gallery count updated

    Note over User,Gemini: Bulk Generate — 10 Parallel Variations
    User->>API: POST /api/bulk-generate/describe {ImageData}
    API->>OpenAI: DescribePersonAsync(imageBytes)
    OpenAI-->>API: personDescription
    API-->>User: BulkDescribeResponse

    loop 10 parallel slots
        User->>API: POST /api/bulk-generate/variation {ImageData, Prompt+description}
        API->>Gemini: RegenerateAsync(imageBytes, combinedPrompt)
        Gemini-->>API: variationBytes
        API-->>User: variation image (streamed slot result)
    end

STARTUP

Key Vault + Auth

  • AddAzureKeyVault on startup (30-min rotation)
  • DefaultAzureCredential — Managed Identity
  • OIDC: challenge → consent → callback → cookie
  • Dev: /dev-login?email= → instant cookie

ANALYSIS

Image Processing

  • Magic byte validation first
  • CV → tags + confidence
  • OpenAI enhance description
  • Gemini regenerate image bytes

BULK

10× Parallel Slots

  • POST /describe — person context
  • 10 concurrent /variation calls
  • Results delivered as each slot resolves
  • No slot blocks another
