Data Lifecycle

End-to-end image data lifecycle: browser ingestion → HTTPS transfer with magic-byte validation → AI processing pipeline → optional persistence in Azure Table Storage.

flowchart LR
    subgraph Ingestion["Ingestion — Client Side"]
        direction TB
        FileInput["File picker / drag-drop\nbrowser File API"]
        Clipboard["Paste from clipboard\nClipboard API bytes"]
        FileInput --> Base64Encode["FileReader.readAsDataURL\n→ base64 string"]
        Clipboard --> Base64Encode
    end

    subgraph Transfer["Transfer — HTTPS"]
        direction TB
        Base64Encode --> HttpPost["POST /api/images/analyze\nContent-Type: application/json\n{ ImageData: base64, Mode, DescriptionLength }"]
        HttpPost --> MagicValidate["Magic byte validation\nFF D8 FF (JPEG)\n89 50 4E 47 (PNG)"]
        MagicValidate --> FromBase64["Convert.FromBase64String\nbyte[] imageBytes"]
    end

    subgraph Processing["Processing — Application Layer"]
        direction TB
        FromBase64 --> CVStep["Azure Computer Vision\nAnalyzeAsync(bytes)\n→ tags[], confidence, description"]
        CVStep --> AIBranch{"Processing Mode"}

        AIBranch -->|"ImageRegeneration"| EnhanceStep["Azure OpenAI\nEnhanceDescriptionAsync\n(description, tags, length)"]
        AIBranch -->|"MemeGeneration"| MemeCaption["Azure OpenAI\nGenerateMemeCaptionAsync\n(tags) → top + bottom"]

        EnhanceStep --> RegenStep["Google Gemini\nRegenerateImageAsync\n(imageBytes, enhancedDesc)\n→ new bytes"]
        MemeCaption --> MemeOverlay["SkiaSharp\nGenerateMemeAsync\n(bytes, top, bottom)\n→ JPEG bytes"]
    end

    subgraph Egress["Egress — Response"]
        direction TB
        RegenStep --> BuildResp["ImageAnalysisResponse\n{ Description, RegeneratedImageData,\nTags, ConfidenceScore, Metrics }"]

        BuildResp --> BlazorRender["Blazor SSR\nImageRegenerationResultsPanel\n"]
        BuildResp2 --> BlazorRender2["Blazor SSR\nMemeResultsPanel\n"]
    end

    end

INGESTION

Client-Side Encoding

  • File picker or clipboard paste
  • FileReader.readAsDataURL → base64
  • Single POST body — no multipart

PROCESSING

AI Pipeline Branches

  • ImageRegeneration: CV → OpenAI → Gemini
  • MemeGeneration: CV → OpenAI caption → SkiaSharp
  • Magic byte guard: JPEG FF D8 FF / PNG 89 50 4E 47

PERSISTENCE

Optional Table Storage

  • User-initiated save only
  • PartitionKey=UserId, RowKey=GUID
  • Kind enum: Original / Regeneration / Meme / BulkVariation
