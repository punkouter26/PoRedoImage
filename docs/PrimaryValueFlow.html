Primary Value Flow — Bulk Generate

Bulk Generate workflow: upload photo → optionally edit & save 10 art-style prompts → GPT-4.1-nano person description → 10 parallel Gemini Imagen3 calls → live streaming results grid.

SETUP

Prompt Management

  • 10 pre-loaded art-style prompts
  • Edit text (max 2000 chars each)
  • Persist to Table Storage per user
  • Load saved prompts on return

PIPELINE

Parallel AI Execution

  • POST /describe — GPT-4.1-nano vision
  • 10× POST /variation — Gemini Imagen3
  • No slot blocks another
  • Results stream live as each completes

OUTPUT

BulkResultsGrid

  • 10-image grid rendered progressively
  • Progress bar shows slot completion
  • Download individual or save to gallery
  • ProgressBar step indicator + elapsed time
