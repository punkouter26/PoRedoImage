Exception & Error Flows

All exception paths: authentication redirects, input validation (magic bytes, base64, length), rate limiting HTTP 429, AI content policy HTTP 422, and service failures.

flowchart TD
    subgraph AuthErrors["Authentication & Access Errors"]
        NotAuth["Unauthenticated request\nto protected page"]
        --> RedirectLogin["Redirect → /login\n401 or cookie missing"]
        RedirectLogin --> LoginAttempt{"Login attempt"}
        LoginAttempt -->|"OIDC failure / timeout"| OIDCFail["OIDC error page\nDisplay error description\nfrom callback params"]

        BadBase64["Non-base64 image data"]

        BadPrompts["Prompts array ≠ 10 items\nor item > 2000 chars"]

    end

    end

VALIDATION

Input Guard Errors

  • HTTP 400: invalid base64 / magic bytes
  • HTTP 400: DescriptionLength 200–500
  • HTTP 400: exactly 10 prompts required
  • Open-redirect prevention on returnUrl

RATE & POLICY

Throttle + AI Policy

  • HTTP 429: 10 req/min per user
  • Retry-After header returned
  • HTTP 422: content_policy_violation
  • Try a different image prompt

SERVICE FAULTS

AI & Storage Failures

  • CV timeout → HTTP 500 + LogError
  • Gemini not configured → HTTP 400
  • OpenAI throttle → propagate retry-after
  • Table Storage fail → /health 503 Degraded
