State Dynamics

Three concurrent state machines: UserImage lifecycle (upload → analyze → enhance → regenerate → save), BulkVariation lifecycle, and BulkPrompt lifecycle (default → edit → persist).

IMAGE LIFECYCLE

Upload → Save

  • Rejected: invalid magic bytes → terminal
  • ContentBlocked: HTTP 422 → terminal
  • Saveable: Regenerated or MemeGenerated
  • Saved: TableStorage upsert → gallery entry

BULK LIFECYCLE

Variations

  • PromptLoaded → Described (GPT vision)
  • 10× parallel GeneratingVariations
  • VariationComplete → optional BulkSaved
  • VariationFailed: Gemini quota/config

PROMPT LIFECYCLE

Prompt Persistence

  • Default 10 prompts on app load
  • PendingSave when user edits
  • POST /prompts → Persisted in Table Storage
  • User can reset back to defaults
