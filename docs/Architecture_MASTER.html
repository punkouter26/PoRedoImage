Blazor + Minimal API

  • Auth: Cookie + Microsoft Entra OIDC
  • Rate limiting: 10 req/min per user
  • /health · /diag · Scalar API docs

AI SERVICES

Three-Layer AI Pipeline

  • Azure Computer Vision — image tagging
  • Azure OpenAI GPT-4.1-nano — description/caption
  • Google Gemini — image regeneration & bulk

OPERATIONS

Observability Stack
