%% PoRedoImage — Auth Lifecycle (DETAILED)

stateDiagram-v2
    direction TB

    [*] --> HostShell

    state "Host shell served (AllowAnonymous)" as HostShell
    HostShell: MapRazorComponents + MapStaticAssets are AllowAnonymous
    HostShell: /_framework endpoints force-tagged AllowAnonymous in Program.cs
    HostShell: (else the fail-closed FallbackPolicy 302s resource-collection.js and WASM never boots)

    HostShell --> InitMask

    state "AuthenticationStateProvider initialization mask" as InitMask
    InitMask: Server ran AddAuthenticationStateSerialization — claims only, never tokens
    InitMask: Client runs AddAuthenticationStateDeserialization
    InitMask: CascadingAuthenticationState is pending; AuthorizeRouteView renders nothing yet
    InitMask: RenderModes.WasmNoPrerender means no server prerender pass to flash

    InitMask --> Resolved: state deserialized

    state Resolved <<choice>>
    Resolved --> Authenticated: principal has an identity
    Resolved --> Anonymous: no principal

    state "Anonymous" as Anonymous
    Anonymous: AuthorizeRouteView NotAuthorized -> RedirectToLogin -> /login
    Anonymous: /api/* returns 401 (never a 302) via ApiAwareRedirectToLogin

    Anonymous --> PickScheme

    state "Choose auth pipeline" as PickScheme
    state PickScheme <<choice>>
    PickScheme --> FakeAuth: Auth:EnableFakeAuth = true AND not Production
    PickScheme --> CookieOnly: no AzureAd:ClientId AND not Production
    PickScheme --> Oidc: AzureAd:ClientId present
    PickScheme --> FailFast: no ClientId AND Production

    state "FailFast" as FailFast
    FailFast: InvalidOperationException at startup
    FailFast: Production must never silently degrade to cookie-only
    FailFast --> [*]

    state "FakeAuth (Dev / Test bypass)" as FakeAuth
    FakeAuth: FakeAuthHandler replaces the ENTIRE pipeline
    FakeAuth: X-Fake-User header -> NameIdentifier + Name claims
    FakeAuth: X-Fake-Roles header -> comma-separated Role claims
    FakeAuth: Missing header -> AuthenticateResult.NoResult (anonymous, not 500)
    FakeAuth: ctor throws if env.IsProduction() — defence in depth
    FakeAuth --> Authenticated

    state "Cookie-only (Development / Test)" as CookieOnly
    CookieOnly: /auth/login/fake?email=... or ?guestId=GUEST########
    CookieOnly: GUEST identity = guest|GUEST + random 8 digits, persisted in LocalStorage
    CookieOnly: SignInAsync(CookieAuthenticationDefaults)
    CookieOnly --> CookieIssued

    state "Microsoft Entra ID OIDC" as Oidc
    Oidc: DefaultScheme = Cookie, DefaultChallengeScheme = Cookie
    Oidc: /auth/login/microsoft -> ChallengeAsync(OpenIdConnect)
    Oidc: Authority https://login.microsoftonline.com/{tenant}/v2.0 (tenant defaults to common)
    Oidc: ResponseType = code · SaveTokens = FALSE (BFF invariant)
    Oidc: Scopes openid profile email · GetClaimsFromUserInfoEndpoint
    Oidc: IssuerValidator accepts only login.microsoftonline.com/.../v2.0
    Oidc: AzureAd:AllowedTenantIds narrows to explicit ValidIssuers when set
    Oidc: OnRedirectToIdentityProvider -> 401 for /api paths instead of a browser redirect

    Oidc --> Callback: authorization code
    state "/signin-oidc callback" as Callback
    Callback --> CookieIssued

    state "BFF cookie handshake" as CookieIssued
    CookieIssued: HardenCookie — HttpOnly = true (JS/WASM can never read it)
    CookieIssued: SameSite = Strict
    CookieIssued: SecurePolicy = Always outside Development (SameAsRequest locally)
    CookieIssued: OIDC nonce/correlation cookies keep their own SameSite=None Secure defaults

    CookieIssued --> Authenticated

    state "Authenticated" as Authenticated
    Authenticated: Server serializes the principal (claims only) to the WASM client
    Authenticated: FallbackPolicy = RequireAuthenticatedUser applies to every un-annotated endpoint
    Authenticated: /auth/me returns name, email, roles, returnUrlValid

    Authenticated --> Policy

    state "Policy evaluation" as Policy
    state Policy <<choice>>
    Policy --> Allowed: RequireAuthorization() satisfied
    Policy --> DiagPolicy: endpoint is /api/diag
    Policy --> Anonymous403: policy denied

    state "DiagnosticsAccess policy" as DiagPolicy
    DiagPolicy: Non-Production — any authenticated user
    DiagPolicy: Production — caller must appear in Diagnostics:AdminEmails
    DiagPolicy: Empty allow-list denies EVERYONE (fail-closed)
    DiagPolicy --> Allowed: on allow-list
    DiagPolicy --> Anonymous403: not on allow-list

    state "Allowed" as Allowed
    Allowed: Handler executes; rate limiter partitions by NameIdentifier

    state "403 / 401" as Anonymous403
    Anonymous403: /api -> status code only. Page routes -> /login or /access-denied

    Allowed --> SignOut: user clicks logout
    Anonymous403 --> Anonymous

    state "Sign out" as SignOut
    SignOut: SignOutAsync(Cookie) always
    SignOut: Dev/Test -> redirect /login
    SignOut: Production -> SignOutAsync(OpenIdConnect) -> /signout-oidc
    SignOut --> [*]
