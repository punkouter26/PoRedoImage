Onboarding Journey

First-run flow from unauthenticated arrival through environment-specific login (Dev cookie or Prod OIDC) to the Studio 'Aha!' moment and gallery save.

flowchart TD
    Start(["🌐 User arrives at\nporedoimage-web.azurewebsites.net"])
    --> CheckAuth{"Authenticated?"}

    CheckAuth -->|"No"| LoginPage["Redirect to /login\nLogin.razor"]
    LoginPage --> EnvCheck{"Environment?"}

    EnvCheck -->|"Development"| DevLogin["Click 'Dev Login'\n→ /dev-login?email=user@test.com\nCookie issued instantly"]
    EnvCheck -->|"Production"| MSLogin["Click 'Sign in with Microsoft'\n→ /challenge-microsoft\nEntra ID OIDC flow"]

    MSLogin --> Consent["Microsoft consent screen\nOpenID + profile scopes"]
    Consent --> Callback["POST /signin-oidc\nCode → token exchange"]
    DevLogin --> Authed
    Callback --> Authed

    Authed["✅ Authenticated\nClaims: NameIdentifier · Email · Name"]
    --> LandStudio["Navigate to /\nStudio.razor — Home page"]

    LandStudio --> UploadHint["'Upload or paste an image'\nImageUploadPanel rendered"]
    UploadHint --> FirstUpload["User uploads first image\n(file picker or paste)"]

    FirstUpload --> PickMode{"Select mode"}
    PickMode -->|"ImageRegeneration"| Regen["POST /api/images/analyze\nMode=ImageRegeneration"]
    PickMode -->|"MemeGeneration"| Meme["POST /api/images/analyze\nMode=MemeGeneration"]

    Regen --> AhaRegen["🎉 'Aha!' Moment:\nAI-regenerated image displayed\nin ImageRegenerationResultsPanel"]
    Meme --> AhaMeme["🎉 'Aha!' Moment:\nMeme with AI caption displayed\nin MemeResultsPanel"]

    AhaRegen --> Gallery["Save to gallery?\n→ POST /api/user-images/save-result"]
    AhaMeme --> Gallery
    Gallery --> UserGallery["View in My Images\n/user-images gallery page"]

AUTHENTICATION

Two Login Paths

  • Dev: /dev-login?email= → instant cookie
  • Prod: Microsoft Entra OIDC → consent → callback
  • Claims: NameIdentifier + Email + Name

FIRST USE

Studio Aha Moment

  • Upload any JPEG/PNG photo
  • Choose: ImageRegeneration or MemeGeneration
  • AI result displayed in seconds

RETENTION

Gallery Save

  • One-click save to personal gallery
  • POST /api/user-images/save-result
  • View all saved images at /user-images
