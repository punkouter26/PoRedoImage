The defining constraint The whole UI runs in the browser. PoRedoImage.Web is an API and BFF host that also happens to serve the shell. Prerendering is deliberately off: the WASM client owns the only DI container holding IWebAssemblyHostEnvironment, ImageSessionService and the deserialized auth state, so a server-side prerender pass could not resolve them. Every architectural decision below follows from that one.

Two API groups share the /api/bulk-generate prefix on purpose: the prompt-CRUD group carries RequireAuthorization plus the idempotency filter, while the AI group carries the rate limiter. Splitting them keeps a cheap prompt save out of the AI budget. /api/pricing is mapped directly, without a group.

Observation Error.razor carries no [AllowAnonymous], so it inherits the assembly-wide [Authorize] from _Imports.razor. An unauthenticated user hitting an error is redirected to /login rather than shown the error page. That is coherent with the forced-login posture, but it does mean the error page is unreachable in exactly the state most likely to produce one.

Why step 9 exists

blank-page class of bug

Most WASM boot assets are static files, covered by MapStaticAssets().AllowAnonymous(). The runtime-generated boot manifest (resource-collection.js) is not a static asset, so that opt-out misses it.

The fail-closed fallback policy would then 302 it to /login. The browser follows the redirect, receives login HTML where it expected a JS module, fails the subresource-integrity check, and never boots — a blank page with no useful error.

The middleware re-tags any /_framework endpoint that lacks an explicit authorization opt-out. Routing has already matched by that point, so the rewrite is precise: every endpoint without the /_framework prefix stays fail-closed.

07

Platform decisions worth knowing

set once in Program.cs and Directory.Build.props

JSON

Source-generated serialization via SharedJsonContext, combined after the default reflection resolver so anonymous types (health responses) still work. Reflection-free and trim-safe on the DTO path.

Options

OpenAiOptions and StorageOptions bind with ValidateOnStart and a custom IValidateOptions<T>, so Key Vault rotation stays hot-reloadable while missing required fields fail at boot.

Resilience

The BFF's own client and both AI clients use the standard handler. The circuit-breaker sampling window is set to 4 minutes — deliberately ≥ 2× the 2-minute attempt timeout, which the handler requires.

Build

TreatWarningsAsErrors with NuGetAuditMode=all and NuGetAuditLevel=low. Vulnerability warnings are not suppressed — a vulnerable dependency breaks the build.

Versioning

MinVer derives assembly versions from git tags; no version number is checked into a project file.

Caching

HybridCache gives an L1 tier with stampede protection — consumed today only by the immutable meme-template catalog; the L2 tier activates when a distributed cache is registered.
