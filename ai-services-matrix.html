🐛 Known issues & resolutions
  • HF fal-ai image generation broken: fal-ai/flux/schnell and fal-ai/qwen-image-edit return HTTP 400 — Model not supported by provider fal-ai. fal-ai is no longer in HF router's provider list. Default switched to Gemini 2.5-flash-image (cheapest working path). HF picker still offered in UI for when fal-ai restores routing.
  • BulkGenerate uses router (fixed): /variation and /reroll now route via IImageGenerationRouter with the picker-driven ImageGenModelId rather than the hardcoded default.
  • MemeGeneration UI spinner fixed: server response no longer sticks the progress bar; both Original and Meme images render with caption & action buttons.
  • Rap Roast vision downscale (fixed): images > 768 KB are downscaled to 1024 px JPEG q85 before being sent to the HF chat-completions endpoint to avoid 413.
  • BulkGenerate serial: 10 slots run sequentially; ~7-8 s each → ~70-80 s total. Could be parallelised like /reroll already is.
  • Meme caption quality: OCR picks up random t-shirt text which the caption model overfits to. Pre-filter OCR text or use only top-tags for captions.
